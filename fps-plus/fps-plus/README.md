# FPS Plus (Fabric, Minecraft 1.21.11)

Più tasti per la stessa azione. Nessun pulsante visibile: in
Opzioni > Controlli > Associazione tasti premi **K** per aprire la schermata dei tasti aggiuntivi.

- Clic su un tasto extra = cambialo; `+` = aggiungine un altro (fino a 4 extra per azione)
- Durante l'assegnazione: Esc annulla, Backspace/Canc rimuove
- Config: `config/hidden_multikeys.json`

Build: `./gradlew build` -> `build/libs/`
(Mappature: Mojang ufficiali. Se la build non parte, aggiorna le versioni in gradle.properties da https://fabricmc.net/develop)
